# Tshwane Bus Services Frontend

React + Vite frontend for the Tshwane Bus Services client portal.

## Requirements
- Node.js 18+ recommended
- npm

## Install
```bash
npm.cmd install
```

## Run in development
```bash
npm.cmd run dev
```

## Build for production
```bash
npm.cmd run build
```

## Preview the production build
```bash
npm.cmd run preview
```

## Pages
- `/` Home
- `/register` Registration
- `/login` Authentication
- `/top-up` Account top-up
- `/scope` Project scope

## Notes
- On Windows PowerShell, use `npm.cmd` instead of plain `npm` if script execution policy blocks the shim.
- The UI uses React Router for page-based routing.
